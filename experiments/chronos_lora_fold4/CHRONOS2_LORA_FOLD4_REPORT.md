# Отчёт по эксперименту: Дообучение Chronos-2 с LoRA на Selection Fold 4

## 1. Цель и контекст эксперимента
Проведение первого строго контролируемого пилотного эксперимента по дообучению модели Chronos-2 с LoRA (Low-Rank Adaptation) через официальный `Chronos2Pipeline.fit(..., finetune_mode="lora")` на Selection Fold 4 (`origin = 89`, внешний прогнозный горизонт: 2025-09-15 — 2025-11-10, 9 недель).

---

- **Full Chronos-2 (120M):** Локальные веса отсутствуют из-за блокировки соединения с AWS CDN (`us.aws.cdn.hf.co`). Зафиксирован статус: `NEED_PRETRAINED_WEIGHTS`. Добавлены строгие проверки конфигурации (`d_model=768, num_layers=12, num_heads=12, d_ff=3072`), официального размера (`477 930 472` байт) и контрольной суммы SHA-256 (`ddcda3c7508bf2528087723e98a20707cc04b7f370ae275a9fd88078ddba4f42`).
- **Chronos-2 Small (28M):** Проверены подлинные предобученные веса в `experiments/urgent_models/chronos2_small/model.safetensors` (размер 113 416 384 байт, SHA-256: `492290ae82bb89f9769e3479ce90b3179de1f33e600c34daa0352531538b23cd`).
- **Стек фактического запуска:** `torch==2.11.0+cu128`, `transformers==5.22.1`, `peft==0.21.2`, `accelerate==1.15.0`, `chronos==2.3.2`, `numpy==2.4.6`, `pandas==3.0.5` (CUDA 12.8, cuDNN 91900 / 9.1.9).
- **GPU / VRAM:** NVIDIA GeForce RTX 3060 Laptop GPU (6 GB VRAM).

## 3. Конфигурация LoRA и строгая временная изоляция

### 3.1. Параметры адаптера LoRA
- `finetune_mode`: `"lora"`
- `r` (rank): 8
- `lora_alpha`: 16
- `target_modules`: `["self_attention.q", "self_attention.k", "self_attention.v", "self_attention.o", "output_patch_embedding.output_layer"]`
- **Обучаемые параметры:** 411 264 из 28 345 888 (**1.45%** от общего числа весов). Полный бэкбоун заморожен.
- `learning_rate`: $1 \times 10^{-5}$
- `num_steps`: 300
- `batch_size`: 32, `gradient_accumulation_steps`: 2 (эффективный batch size = 64).

### 3.2. Доказательство отсутствия утечки (Temporal Isolation)
1. **Внешний тестовый горизонт:** недели `89..97` (2025-09-15 — 2025-11-10, 9 недель).
2. **Внутренняя валидация:** недели `80..88` (2025-07-14 — 2025-09-08, 9 недель непосредственно перед внешним cutoff).
3. **Обучающая выборка (`train_tensor`):** недели `0..79` (длина 80 недель, строго **до** внутренней валидации).
4. **Обучающие окна:** при сэмплировании окон `context_length = 52` + `prediction_length = 9` внутри `train_tensor` максимальный индекс целевого окна равен `79`.
5. **Временной зазор:** $\text{max}(\text{train\_target}) = 79 < \text{start}(\text{val}) = 80 \le \text{end}(\text{val}) = 88 < \text{start}(\text{test}) = 89$. Пересечение равно строго **0.0%**.
