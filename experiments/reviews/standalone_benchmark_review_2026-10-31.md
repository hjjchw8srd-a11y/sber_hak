# Проверка отчёта standalone / foundation registry

Прочитаны run_standalone_models_benchmark.py, evaluate_all_stock_check_and_all_folds.py, download_and_verify_registry.py, реестр, сохранённая summary. Обучение и новые загрузки в ходе этого аудита не выполнялись. Код модели/CSV не изменялись, push не выполнялся.

## Критическая ошибка идентификации модели

run_standalone_models_benchmark.py использует колонку stock_lgbm_only из experiments/model_improvements/all_stock_5folds/keyed_predictions как одиночный LightGBM Stock 1M. Источник колонки — evaluate_all_stock_check_and_all_folds.py: это финальный прогноз ансамбля с заменой только компонента LightGBM на stock-вариант. Это не выход одиночного регрессора и не новый Scale1M Dual. Применение LegacyP к этому столбцу повторяет постобработку. Равенство continuous/rint объясняется уже целочисленным входом.

Аналогично all_stock_ensemble из этого старого файла — вариант .729252/.754471, а не последний Scale_1M_Dual_0.5 .728728/.753387. Summary CSV содержит первую пару, текст отчёта в основной таблице подставляет вторую. Нельзя объединять их под одним run ID.

Вывод «лучший одиночный LightGBM .729315, ни одна одиночная модель не выигрывает» не подтверждён этим бенчмарком. Старые результаты TFT остаются отдельной полезной информацией, но не исправляют ошибку.

## Остальные ограничения

- Сегменты volume/sparsity рассчитываются по всему data до цикла folds, включая будущую относительно cutoff историю. Это допустимо лишь как явно retrospective diagnostic, не как исторически доступный режим для выбора модели. Считать отдельно по data.week < val_start каждого окна.
- Скрипт переоценивает сохранённые прогнозы, не вызывает inference моделей. Из времени этого скрипта нельзя получить скорость модели/RAM/VRAM, несмотря на docstring.
- Никакая новая foundation-модель фактически не оценена. Таймаут TLS подтверждает неудачное соединение, но не доказанную конкретную блокировку CloudFront.
- Реестр проверяет соединение/read1024bytes, это не загрузка/проверка целостности весов. Зафиксированные revision должны использоваться в фактическом URL/Hub download; main не заменяет pinned revision.
- Sundial указан с ошибочным model ID thuml/Sundial-128M. Официальный ID thuml/sundial-base-128m, карточка Apache2: https://huggingface.co/thuml/sundial-base-128m . HTTP401 неверного ID не доказывает gated-доступ правильной модели.
- Вместо запрошенного TimesFM2.5 проверялся2.0. Исправить на google/timesfm-2.5-200m-pytorch: https://huggingface.co/google/timesfm-2.5-200m-pytorch .

## Следующие задачи Antigravity

1. Пометить текущие строки LGBM_Stock_1M_* как INVALID_MODEL_IDENTITY, сохранить прежние артефакты, отозвать заключение о лучшей одиночной модели. Не переносить эти метрики в манифесты.
2. Для каждого fold получить именно OOF-компонент Scale1M Dual, обученный строго до cutoff: сохранить p_sale, q_l1, q_l2, expected=p_sale*(.5*q_l1+.5*q_l2), after_gate. Полный финальный bundle нельзя применять к старым окнам: он обучался на их фактах.
3. Сравнить одиночный LightGBM по expected/after_gate с отдельно указанными обработками; raw ensemble пересобрать из тех же компонентов и сохранить. Строгие ключи, finite и config/data hashes. Контроль tests должен быть exact-run, не переименованным старым файлом.
4. Исправить сегменты и registry IDs, сверить declared revision с фактическим URL. Статусы новых моделей: NOT_EVALUATED / DOWNLOAD_FAILED, не «проиграла ансамблю».
5. Главный следующий технический шаг — получить настоящие веса хотя бы одной приоритетной модели. Одна корректная попытка официальным Hub-клиентом с разумным timeout и pinned revision, с логом ошибки; не менять сетевые настройки компьютера. Если текущая сеть не позволяет, скачать только публичные веса на другом доступном компьютере/в пользовательском Colab и перенести локально вместе с config/license/checksum. Данные хакатона загружать туда не требуется. Не утверждать, что это уже выполнено.
6. После появления весов выполнить настоящий smoke, затем согласованный standalone benchmark. Предыдущая цель поиска сильной одиночной модели не выполнена; не подменять её очередным объявлением ансамбля чемпионом.
