# Оформление проекта для портфолио

Ветка codex/portfolio от 472f4a0. Изменения относятся к документации;
обучение, веса, прогнозы и исторические артефакты не изменялись.

Добавлены README, инструкция запуска, архитектура, сводка результатов,
карта экспериментов и памятка для резюме/собеседования. Устаревшее описание
API LGBM52 сохранено в docs/archive; текущая страница ссылается на актуальный
ансамбль 45/37/9/9 и его конфигурацию.

Метрики ансамбля взяты из five_folds_enhancements_results.json,
поздние Timestral-метрики — из harmonized_5fold_metrics.csv, усреднены
по пяти фолдам. Новые эксперименты при оформлении не запускались.

Отдельно отмечены ограничения: отсутствие исходных данных в Git,
переиспользование временных окон, различие локального и рангового score,
неподтверждённая Docker-сборка, разные статусы research и сохранённого API.
