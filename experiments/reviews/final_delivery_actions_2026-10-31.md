# Завершение проекта перед сдачей

Исходный коммит: 9aae39f, ветка tests. Эксперименты Timestral завершены Antigravity.

Основным решением оставлен champion_all_stock_ensemble. Переобучение не выполнялось:
подтверждённого устойчивого выигрыша Timestral над текущим ансамблем нет.
Финальный экспериментальный 5%-бленд не эквивалентен проверенному рецепту:
в генераторе смешаны уже обработанные прогнозы champion и Timestral,
в исторической проверке использованы непрерывные прогнозы другого ансамбля.
Этот CSV не повышен до статуса основного.

Проведено полное локальное воспроизведение champion_clipped_score.csv из исходных
дневных sales/stock с отсечением по 2026-07-26. Все 79101 прогнозов совпали точно;
сумма 216701, максимальное отклонение 0. Время вычисления Predictor в первой
проверке — 21.28 секунды (не включает чтение входных CSV).

Добавлен generate_submission_release.py: воспроизводимый CLI для сдаваемого
варианта, строгая проверка полной сетки ключей, дат, конечности значений,
one-to-one сравнение с эталоном и JSON с результатами проверки.
Второй независимый запуск нового CLI также совпал с эталоном по всем значениям.

Добавлен build_final_delivery.py: сборка отдельного архива кода и весов,
без перезаписи старого defense_package_candidate_lgbm52.zip. Сборка требует
успешных 13 тестов API и точного воспроизведения submission. Архив содержит
актуальную инструкцию, результаты пяти исторических окон и контрольные суммы.
Проверяется ZIP CRC и совпадение хешей всех файлов моделей после упаковки.

Первый запуск API-тестов ограниченная среда заблокировала на локальных сокетах;
локальная HTTP-проверка получила WinError 10013. Повторные API-тесты запущены
с разрешённым локальным доступом. Источник окончательного статуса —
final_api_verified_2026-10-31.log и delivery_final/manifest.json.
Docker отсутствует; сборка Docker не объявляется проверенной.
