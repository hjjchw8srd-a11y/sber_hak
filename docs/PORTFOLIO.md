# Как представить проект

## Короткое описание для резюме

**Прогнозирование спроса в розничной сети.** Разработка пайплайна недельного
прогноза для 8 789 пар «склад — товар» на горизонт девять недель. Подготовка
данных продаж и остатков, временная валидация, ансамбль TFT/LightGBM/CatBoost,
исследование Chronos-2 и Timestral с LoRA. Сохранение моделей, воспроизводимый
инференс и HTTP API на FastAPI.

## Что показать на собеседовании

1. Задача и редкий спрос: почему одного RMSE недостаточно.
2. Агрегация: почему продажи можно суммировать по дням, а остатки требуют другого подхода.
3. Временная валидация: какие данные доступны в момент прогноза и где возникает утечка.
4. Ансамбль: что дают разные модели и почему новая нейросеть не обязательно улучшает смесь.
5. Инженерная часть: API, локальные веса, повторное получение прогноза и проверки.
6. Ограничения: переиспользование фолдов, небольшие улучшения и непроверенный Docker.

Для рассказа достаточно главной страницы и одного демонстрационного запуска.
Не нужно объяснять каждый исторический скрипт или заявлять результаты, которые
есть только в предварительном отчёте.

## Личный вклад

В резюме используйте только действия, которые можете объяснить и воспроизвести.
Проект создавался с использованием AI-инструментов для реализации и анализа.
При обсуждении полезно разделять постановку экспериментов, проверку результатов
и написание кода с помощью инструментов. Понимание ограничений решения — часть
профессионального рассказа, а не недостаток проекта.
